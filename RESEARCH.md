# Журнал исследования Lamoda

Цель — AP@20% выше 0,85. Для февраля обучение включает январь, для марта — январь и февраль. Каждый контрольный месяц содержит 25 000 клиентов. Веса и признаки подбирались по этим двум срезам.

| Проверенная версия | Февраль | Март |
|---|---:|---:|
| Предыдущая посылка submission_features.csv | 0,75210 | 0,76130 |
| Та же смесь с вероятностями переходов между категориями | 0,75465 | 0,76282 |
| Переходы и отдельные модели для четырёх групп клиентов, веса 1:1 | 0,75793 | 0,76961 |

**Переходы.** Для последней категории клиента и пары последних категорий оценивали, какие категории обычно следовали за ними у этого клиента. Частоты сглаживали долями категорий в истории. По каждой кандидатной категории сравнивали прогнозную дату повторной покупки с серединой целевого квартала.

**Сегменты.** Отдельно обучали модели для одного заказа, короткой или однородной истории, а также для двух групп остальных клиентов. Их разделяли по тому, попадает ли очередная ожидаемая покупка, рассчитанная по медианному интервалу, в диапазон от −14 до +104 дней относительно даты прогноза.

**Другие эксперименты.** У общей модели со всеми прежними признаками было 0,74695 / 0,75674. С переходами стало 0,75049 / 0,76248. При добавлении статистик смены категорий по окнам — 0,74991 / 0,76881. Индивидуальные серии заказов, разделённые по длительности пауз, вместе с переходами дали 0,75344 / 0,76272. Поправки по брендам и подкатегориям, прогноз по аналогичным корзинам, нейросеть по последовательности чеков и обучение на искусственных исторических срезах не дали устойчивой прибавки к смеси.

**Состояние этапа.** Проверены прогнозы на временных срезах. Следующий шаг — сравнить компактный отбор признаков и калибровку, выполнить новый ноутбук на исходном ZIP и сохранить прогноз для теста. Новая оценка Kaggle пока неизвестна.

**Контрольная точка воспроизведения.** Ноутбук [lamoda_groups.ipynb](lamoda_groups.ipynb) запускается с исходного ZIP. Первая завершённая проверка сохранена в [validation_groups.csv](validation_groups.csv). При прерывании запустите ноутбук с начала. После восстановления таблиц функция `cached_forecast` подхватит завершённые этапы обучения из `.checkpoints/lamoda_groups/` на этой машине. В новой среде без локального кэша модели пересчитываются по сохранённому коду. Для каждого следующего этапа фиксируем гипотезу, сравнение на обоих месяцах и оставшуюся проверку в этом журнале.
