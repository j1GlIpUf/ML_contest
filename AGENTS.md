# Правила для агентов (Lamoda repeat purchase)

- Контроль: `AP@20%` = 0.77701 (февраль) / 0.78434 (март), покупателей в топ-5000 = 4166 / 4172.
- Новых внешних данных нет: работаем только с таблицами из `data/` (`train.csv`, `test.csv`, `orders.parquet`, `products.parquet`).
- НЕ редактируй `.ipynb`, `submission_*.csv`, `validation_*.csv` и чужие файлы во время экспериментов.
- Один эксперимент = один новый скрипт `research/exp_<name>.py` и один отчёт `research/results/<name>.csv`.
- Жёсткий запрет на утечки:
  - признаки считаются строго при `order_date < scoring_date`;
  - для февраля обучение только на январе; для марта — на январе и феврале;
  - отбор фич, скейлинг, калибровка и OOF-кодирование — строго внутри `fit`.
- Экономия вывода и CPU:
  - отключай логи обучения (`verbosity=-1`, без прогресс-баров);
  - используй `n_jobs=4` или `threadpool_limits(limits=4)`;
  - не печатай длинные таблицы — в stdout только финальная сводка на 5–10 строк.
- Лимит отладки: если скрипт не запускается после 3 попыток починки — остановись и кратко опиши ошибку.
- Финальный ответ воркера (строго по шаблону):
  1. Изменённые/созданные файлы.
  2. Команда запуска.
  3. Таблица: `Feb AP@20%`, `Mar AP@20%`, `delta vs 0.77701/0.78434`, `buyers_top5000 (Feb/Mar)`.
  4. Риски и найденные проблемы (1–3 строки).
