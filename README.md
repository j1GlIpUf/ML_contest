# Lamoda × ВШЭ · Кто купит снова?

Модель ранжирует клиентов по вероятности покупки в ближайшие три месяца. Итоговый прогноз на 1 апреля 2022 года содержит 25 000 клиентов. На двух временных проверках выбранная модель получила **0,76002** за февраль и **0,77011** за март по AP@20%. Цель **0,85** остаётся открытой.

### Как проверяли

В обучающей выборке три группы по 25 000 клиентов. Для февральской проверки модель училась на январе, для мартовской — на январе и феврале. Каждый признак использует только заказы до даты прогноза конкретного клиента. Трёхмесячные окна целевой покупки пересекаются по календарю. Эти проверки оценивают перенос между группами клиентов.

AP@20% учитывает первые 5 000 клиентов на каждом срезе. На каждой позиции покупателя берём долю покупателей от начала списка до этой позиции. Сумму делим на минимум из 5 000 и общего числа покупателей в срезе.

### Что дали признаки и модели

| Эксперимент | Февраль | Март |
|---|---:|---:|
| Базовые признаки заказов | 0,62328 | 0,64908 |
| Динамика активности и сезонность | 0,64206 | 0,66972 |
| Динамика и персональный ритм покупок | 0,69766 | 0,71361 |
| Циклы по категориям и последовательности корзин | 0,73082 | 0,74099 |
| Общая модель со всеми итоговыми признаками | 0,74695 | 0,75674 |
| Общая модель и модели для разных типов истории | 0,75137 | 0,75884 |
| Первая смесь с ранжировщиком LightGBM | 0,75210 | 0,76130 |
| С вероятностями переходов между категориями | 0,75465 | 0,76282 |
| С персональными сериями заказов и моделями по четырём группам | **0,76002** | **0,77011** |

- **Давность относительно ритма клиента.** Добавление среднего и медианного интервала, их разброса и разницы между давностью и обычным интервалом дало самый большой прирост среди последовательных расширений в таблице. У покупателей с двумя-тремя заказами особенно информативно, попадает ли ожидаемая следующая покупка внутрь прогнозного квартала.
- **Состав корзины.** Для более длинных историй проверили интервалы возврата к категории и бренду, последовательности последних заказов и время ожидания после похожей корзины. Для многокатегорийного заказа сравнили выбор основной категории по числу позиций и по стоимости.
- **Выбор модели.** CatBoost на признаках циклов и последовательностей дал 0,71525 и 0,73586. Гистограммный бустинг на тех же признаках оказался сильнее на обеих проверках. Отдельные эксперименты с более глубокими деревьями и дополнительными сезонными признаками не дали стабильного улучшения.
- **Переходы и группы клиентов.** Новое решение оценивает вероятную следующую категорию по последним одной или двум категориям клиента. Четыре отдельных классификатора учитывают длину истории, однородность корзин и ожидаемую дату повторной покупки. Выбранная смесь даёт 50% веса прогнозу этих классификаторов и по 25% двум вариантам общей смеси с ранжировщиком. В каждом месяце новая модель подняла в первые 5 000 клиентов на 33 покупателя больше предыдущего решения. Выбор признаков и весов использует оба среза.

Public score первой посылки — **0,65960**. Для итоговой посылки в таблице приведены локальные результаты.

### Как воспроизвести

1. Скачайте архив соревнования и положите `lamoda-hse-repeat-purchase-2026.zip` рядом с ноутбуком. Можно также распаковать файлы в `data/` или указать путь к архиву или каталогу через `LAMODA_DATA`. [Данные Kaggle](https://www.kaggle.com/competitions/lamoda-hse-repeat-purchase-2026/data)
2. Из корня репозитория создайте окружение. Для проверенного запуска использовался Python 3.12.
3. Откройте выбранный ноутбук и выполните все ячейки сверху вниз. Итоговый ноутбук сравнит модели, переобучит их на 75 000 клиентах и запишет `submission_groups.csv`. Последняя ячейка проверит состав клиентов, диапазон вероятностей и содержимое сохранённого файла.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install jupyterlab numpy==2.3.5 pandas==2.2.3 scikit-learn==1.8.0 pyarrow==26.0.1 lightgbm==4.7.0
jupyter lab lamoda_groups.ipynb
```
